# input-tweaks

Background program for macOS that adds trackpad gestures and media key control.

| Input | Where | Action |
| --- | --- | --- |
| 3 finger swipe up | Firefox, Chrome, Edge | `Cmd+T` (new tab) |
| 3 finger swipe down | Firefox, Chrome, Edge | `Cmd+W` (close tab) |
| 3 finger click | All apps | Middle click |
| Play/pause, next, previous keys | All apps, when Spotify runs | Control Spotify |

Install with `./install.sh`, then give Accessibility permission. Remove with `./uninstall.sh`.
